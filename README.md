# my-java-app

Simple Spring Boot REST API with Java 21.

## Quick Start

```bash
./local/build.sh      # build JAR
./local/run.sh        # run locally on port 8080
```

## Endpoints

- `GET /hello` — returns "Hello, World!"
- `GET /actuator/health` — health check
